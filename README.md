# Spieltag – Fußballturnier

Installierbare Web-App zur Verwaltung eines eintägigen Fußballturniers. Der Spielplan wird automatisch aus den Teams erstellt; die Spiele lassen sich auf bis zu zwei Plätzen parallel anzeigen.

## Auf dem iPhone installieren

1. Öffne die veröffentlichte Spieltag-Seite in Safari.
2. Tippe auf **Teilen** und wähle **Zum Home-Bildschirm**.
3. Öffne Spieltag anschließend über das neue Symbol.

## Speicherung

Turnierdaten werden im Browser des jeweiligen Geräts gespeichert. Eine automatische Synchronisierung zwischen iPhone und Mac ist noch nicht eingerichtet.
